# 合约爆仓多空观测智能体 · 战情室

独立开发的本地 Web Agent 参赛作品，不属于币安官方产品，不提供交易功能，不构成投资建议。

**一句话定位：不猜涨跌，只报告「这个合约近 24 小时，多空两边谁在被爆仓、爆了多少、战况激不激烈」。**

## 一屏速览

| 问题 | 答案 |
|---|---|
| 它报告什么？ | 单币种 24h 多头/空头爆仓分布、单笔大额爆仓、未平仓名义价值、全局多空账户比、「平稳 ◆ / 交火 ◆◆ / 激战 ◆◆◆」战况等级 |
| 数据哪来？ | 币安官方：合约公开实时接口（持仓量/价格/多空比/资金费率/K 线，自动选路）+ 官方开源数据仓库（K 线/合约指标/资金费率归档）+ 官方 CLI |

| 谁出结论？ | 自研规则引擎（`sources.py`，网页与命令行同一段代码、一行未改），可复现、不依赖大模型 |
| 怎么验？ | 三条命令自己跑，见 `AGENT.md`「三条核查命令」 |
| 要不要密钥？ | 全程不需要 API Key |

## 两种用法，同一个引擎

- **网页**（`python agent.py web`）：上下卡片式布局——概览、爆仓/持仓双卡片、大额事件区、综合报告区；
- **命令行战报**（`python agent.py BTCUSDT`）：五栏战报——战况通报 / 伤亡统计 / 重大伤亡 / 兵力与士气 / 参谋提示。

## 快速开始

需要 Python 3.10+，无需 API Key：

```bat
python agent.py web --port 8001
python agent.py BTCUSDT
python agent.py BTCUSDT --official
python agent.py "用官方归档看看 ETHUSDT"
```

第一条起本地网页；第二条出命令行战报（官方合约实时接口，自动选路）；第三条走官方开源数据仓库
（T+1，折算口径）；第四条自然语言自动选通道。

## 四条侦察线路（数据通道）

| 线路 | 命令 | 数据来源 |
|---|---|---|
| 默认（自动选路） | `python agent.py BTCUSDT` | 官方合约实时接口——先直接连，连不上就自动换本机上网工具的 6 个通道（与网页同口径） |
| 强制刷新 | `python agent.py BTCUSDT --live` | 同上，重新选路 |
| 官方 CLI | `python agent.py BTCUSDT --skill` | 官方 CLI `binance-cli request` 直取（连不上时如实回退并标注） |
| 官方归档 | `python agent.py BTCUSDT --official` | 官方开源数据仓库（K 线+资金费率折算爆仓压力 + 合约指标真实持仓量/账户比，T+1） |

## 这些数字别过度解读

- **实时战报需要电脑能连上币安**（上网工具开着就行）；连不上时程序如实报错、不编数据 ——
  想看历史数据又不想受网络影响，用 `--official` 走官方存档；
- **爆仓金额是折算估算**：官方实时强平明细端点已下线（实测 404）、历史也没有强平明细归档 ——
  爆仓金额 = 「K 线振幅 × 资金费率」折算（与网页部署版同一套公式，JSON 里 `estimate=true` 可核验）；
  持仓量、价格、多空账户比、资金费率为官方真实值，战报里逐处标注；
- 引擎原有的「持仓趋势」示意曲线与「代表性大额补录」**不进命令行战报**（战报只报真实数据）；
- 网页版在接口不可用时展示演示数据（原作品设计，页面有标注）；命令行版绝不使用演示数据；
- 账户比是账户数之比，不等于资金量之比；爆仓数据不预测未来，不构成投资建议。

## 数据来源与免责

- 官方合约公开实时接口（`fapi.binance.com` 公开端点）：强平订单、未平仓量、全局多空账户比；
- 币安官方开源数据仓库（`data.binance.vision`）：合约 K 线、合约指标、资金费率历史归档；
- 官方 CLI（`binance-cli`，官方技能文档记载的 `request` 用法）；
- 网络或接口受限时，网页展示演示数据并在页面注明；正式研究应以实时接口返回为准；
- 本作品不提供交易功能，不构成投资建议。
