# 盘口损耗研判智能体 · 计量所

一个围绕**交易前风险检查**的本地 Web Agent 参赛作品，不属于币安官方产品，不提供交易功能，不构成投资建议。

**一句话定位：下单之前，先把「这笔单子会被盘口吃掉多少钱」算清楚。**

## 一屏速览

| 问题 | 答案 |
|---|---|
| 它检定什么？ | 按 1,000 / 5,000 / 10,000 / 30,000 USDT 四档金额模拟吃单现货盘口：理论成交均价、滑点偏差、预估磨损、使用档位、未成交金额、滑点急剧放大的临界金额、低/中/高/极高四级风险评级 |
| 数据哪来？ | 币安官方：公开行情入口盘口端点 `/api/v3/depth`（自动选路）+ 官方开源数据仓库逐笔成交归档 + 官方 CLI；情绪参考来自 alternative.me（第三方，逐处标源） |
| 谁出结论？ | 自研规则引擎（`sources.py` 的 `calculate_slippage` / `_walk_book`，网页与命令行同一段代码、一行未改），可复现、不依赖大模型 |
| 怎么验？ | 三条命令自己跑，见 `AGENT.md`「三条核查命令」 |
| 要不要密钥？ | 全程不需要 API Key |

## 两种形态，同一个引擎

- **网页**（`python agent.py web`）：盘口深度图、滑点结果、情绪曲线、历史记录、可复制 Markdown 报告；
- **命令行检定证书**（`python agent.py BTCUSDT`）：粗框证书 —— 送检样品 / 检定环境 / 检定项目 / 检定结论 / 检定须知。

## 快速开始

项目仅依赖 Python 标准库，不需要第三方包或 API Key：

```bash
python agent.py BTCUSDT --side buy --amount 10000     # 检定证书（官方盘口快照，自动选路）
python agent.py BTCUSDT --official                    # 官方归档：T+1 逐笔成交流重建（含 10 万/100 万大额档）
python agent.py "看看 ETHUSDT 卖三万 U 的滑点"          # 自然语言自动选通道
python agent.py web --port 8001                       # 本地网页
python agent.py feargreed --history                   # 恐慌贪婪指数（第三方 alternative.me）
```

原有命令全部保留：`slippage`（等价默认通道）、`feargreed`、`web [--dual]`。

## 四条送检通道（数据通道）

| 通道 | 命令 | 检定基准 |
|---|---|---|
| 默认（自动选路） | `python agent.py BTCUSDT --side buy --amount 10000` | 官方公开行情入口盘口快照（先直连、连不上自动换本机上网工具通道，与网页同口径） |
| 强制刷新 | 加 `--live` | 同上，重新选一遍线路 |
| 官方 CLI | 加 `--skill` | 官方 CLI `binance-cli request` 直取（连不上时如实回退并标注） |
| 官方归档 | 加 `--official` | 官方开源数据仓库：锚定日全部逐笔成交重建价格阶梯（约 0.001% 一档，T+1） |

## 这些数字别过度解读

- **静态盘口估算不包含**手续费、网络延迟、撤单、成交顺序变化和突发波动；
- **盘口是瞬时快照**：快照编号与出具时间印在证书上，快照之后盘口变了结果就变；
- **归档通道是「成交分布重建」**：官方没有盘口快照的历史归档（盘口是瞬时的），该通道用当天真实
  逐笔成交重建阶梯（每档量级=当日累计成交量）→ 适合测**大额冲击**，小额档通常不跨档（偏差≈0）是口径特性；
- **「偏差 0」不是算错**：深度极好的品种（如 BTC）小额吃单不跨出第一档，证书会自动补这句说明；
- 恐惧贪婪指数来自 **alternative.me（第三方公开接口，非币安数据）**；
- 不构成投资建议。

## 部署到 Netlify（可选）

项目已加入 Netlify Functions（`netlify/functions/analyze.js` / `history.js` / `_shared.js`）：

1. 打开 Netlify 控制台并登录；
2. **Add new project → Deploy manually**；
3. 把**整个项目文件夹**拖入上传区域（不要只拖 `static`）；
4. 部署完成后打开网址，点击「启动 Agent 分析」测试实时盘口。

在线版历史记录保存在浏览器 `localStorage`，清除数据或换设备不保留 —— 适合演示，不是永久数据库。
